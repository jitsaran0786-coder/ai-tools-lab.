# AI Tools Lab

## Description

AI Tools Lab is a Python project that demonstrates basic programming utilities and sorting algorithms. It includes a Bubble Sort implementation and useful utility functions for common tasks.

## Features

- Bubble Sort algorithm
- Palindrome checking
- Word counting
- Celsius to Fahrenheit conversion

### Utility Functions

The `utils.py` file provides:
